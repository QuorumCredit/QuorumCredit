### Issue #1070: Circuit Breaker
Auto-pause protocol when defaults cascade.

**Location**: `src/circuit_breaker.rs` (160 lines)

```rust

let rate = circuit_breaker::calculate_default_rate(10, 100);  // 1000 bps = 10%

// Try to activate with cooldown enforcement

```

**Features**:
- Auto-pause when rate ≥ threshold
- 1-hour cooldown to prevent thrashing
- Governance-controlled threshold

## FAQ

**Q: How does lazy detection reduce costs?**
A: Instead of O(N) scanning on every block, defaults are flagged on-demand when accessed (O(1)).

**Q: What's the circuit breaker cooldown for?**
A: Prevents rapid trigger-pause-resume cycles. Default is 1 hour.

**Q: How is insurance funded?**
A: Via loan disbursement premiums (configurable %) + admin contributions.

**Q: Can I disable these features?**
A: Yes. Set `insurance_fund_premium_bps = 0` and `default_rate_threshold = 10_000`.

**Q: What happens when insurance fund is depleted?**
A: Claim fails with `InsurancePoolEmpty` error. Admin must contribute.
